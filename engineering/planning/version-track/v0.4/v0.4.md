# v0.4 — Ocharo sign-in

*Last updated: 2026-11-01*

**Status:** 🚧 In Progress · **Type:** Feature · **Started:** 2026-11-01 · **Completed:** —

> Ocharo signs in end to end through its own instance by two methods: email and password with a confirmed email, and
> a phone code sent by Ocharo's Telegram bot. Settings and contracts: the
> [sign-in configuration analysis](../../../research/sign-in-config-2026-10/sign-in-config-2026-10.md).

### Iteration 1 — Passwords and email

- [ ] Ability to set password, sign-in and lockout rules from `Identity:*` settings
- [ ] Ability to send confirmation and reset emails over SMTP, with a local mail sink
- [ ] Ability to confirm an email and reset a password through the account API
- [ ] Ability to change a password with the `None`, `Code` or `Link` confirmation
- [ ] Ability to require a password change at sign-in when the password breaks the current rules
- [ ] Fix bearer sign-in answering 500 on a cookie-only instance

### Iteration 2 — Phone by Telegram

- [ ] Ability to keep one-time codes hashed in the database and shared by instances
- [ ] Ability to link a Telegram chat to a phone through the bot's start link and shared contact
- [ ] Ability to sign in by phone with a code the bot sends
- [ ] Ability to create a person on the first phone sign-in while sign-up is on

### Iteration 3 — Hosted pages

- [ ] Ability to sign in, sign up and confirm an email on the hosted pages
- [ ] Ability to reset and change a password on the hosted pages
- [ ] Ability to sign in by phone and link Telegram on the hosted pages
- [ ] Ability to show an app's theme and background on the hosted pages

### Iteration 4 — Ocharo

- [ ] Ability for Ocharo's apps to sign in through Ocharo's instance and return signed in

### Verification

- [ ] Run the backend tiers and the frontend lint, tests and build → all green
- [ ] Sign up locally, confirm from the mail sink, sign in through `/connect/authorize` → back at the client with a code
- [ ] Change a password under each confirmation type → refused without the code or link, changed with it
- [ ] Sign in by phone with a real bot on Ocharo dev → code arrives in Telegram, signed in
- [ ] Sign in to Ocharo dev by both methods → Ocharo shows the signed-in person
