# v0.2 — OIDC provider core

*Last updated: 2026-10-27*

**Status:** 🚧 In Progress · **Type:** Feature · **Started:** 2026-10-27 · **Completed:** —

### Iteration 1 — Schema

- [x] Ability to create the identity schema from the module's migrations
- [x] Ability to migrate an instance as an explicit deploy step
- [x] Ability to key accounts on uuid v7 ids without generic entities

### Iteration 2 — Signing keys

- [ ] Ability to sign tokens with keys from host files
- [ ] Ability to refuse a production boot on missing or ephemeral keys
- [ ] Ability to rotate signing keys with an overlap window

### Iteration 3 — OIDC server

- [ ] Ability to register apps by configuration
- [ ] Ability to sign an app in through the code flow with PKCE
- [ ] Ability to discover the issuer's metadata and keys
- [ ] Ability to sign out of an app through end-session
- [ ] Ability to emit the contract claims in tokens

- [ ] Run the backend test tiers → every test green
